1  DATA IN swappable feed adapters — nothing above this layer knows which feed it is talking to
DatameetFeed REAL
Station master, roster and working timetable. 8,697 stations, 5,208 trains, 417,080 scheduled calls. datameet/railways · CC0
OpenMeteoFeed REAL
Observed weather per corridor segment. Fog index derived from dew-point depression, humidity, temperature and wind. ERA5 via Open-Meteo · no key
LiveFeed REAL
Running position and delay. No public archive of past arrivals exists, so history is accumulated by polling into an append-only store. RailRadar · NTES when IR provides it
2  CORRIDOR BUILDER the block-section graph, measured from the timetable rather than estimated
Spine & segments Station sequence of a reference train; segments anchored on its real commercial halts.
km posts Great-circle between real coordinates, scaled to the published route distance.
Sectional speed The speed implied by the fastest booked run over each section.
Recovery padding Booked run time minus free-run time. 3.7% on a Rajdhani, 31% on a Janata Express.
3  FORECAST CORE every remaining station forecast in one shot — the horizon is a feature, so error never compounds
A Free-run time
LightGBM on conflict-free section runs. The predictable part, learned on its own. MAE 0.61 min / section
B Conflict simulator
Every train advanced over the block graph until it conflicts. Precedence resolved by priority rules. names the blocking train
C Learned residual
LightGBM quantile loss corrects what the rules cannot capture. Direct multi-horizon, never chained. monotone quantiles
D Calibrated window
Conformalised quantile regression, conditioned on horizon bucket, segment and time of day. 80% window · 78.4% achieved
4  EVALUATION
Temporal holdout — trained on earlier days, scored on later ones. Carry-forward baseline computed on exactly the same rows.
CARRY-FORWARD 26.9 min

Broken out by horizon, segment, time of day and month — a pooled number hides where a model fails.
5  DECISION SURFACES what the window is actually for
Arrival window Every remaining station, with an interval whose coverage is audited.
Connection risk Make-probability from the predictive CDF. Reliability error 0.006.
Costed precedence Which train goes first, and what the other call costs in network-minutes.
